# Data Dictionary — every column in plain English

These are the exact column names used in the CSV files, the dashboards and
Power BI. (The database layer in `sql/` uses matching snake_case names —
`product_code`, `order_date`, … — and `python/etl_pipeline.py` maps between
the two, which is standard ETL practice.)

**Revenue rule:** revenue and sales KPIs count **Delivered** orders only.
Returned and Cancelled orders are measured separately as rates.

## dim_products.csv — one row per product
| Column | What it means |
|---|---|
| Product Code | Unique code for the product, e.g. SKU-101 |
| Product Name | The product's name, e.g. Wireless Earbuds Pro |
| Product Category | Electronics, Apparel, FMCG, Home & Living, Automotive, Sports or Beauty |
| Selling Price (INR) | List price of one unit, in Indian Rupees (₹) |
| Unit Cost (INR) | What one unit costs the business, in ₹ (used for margin) |

## dim_customers.csv — one row per customer
| Column | What it means |
|---|---|
| Customer ID | Unique customer number, e.g. CUST-10001 |
| Customer City | The customer's home city |
| Customer Region | North, South, East or West India |
| Acquisition Channel | Where the customer signed up: Mobile App, Website or Marketplace |
| Signup Date | The day the customer registered |

## fact_orders.csv — one row per order
| Column | What it means |
|---|---|
| Order ID | Unique order number, e.g. ORD-500001 |
| Order Date | The day the order was placed |
| Customer ID | Who ordered (see dim_customers — delivery city and region come from there) |
| Product Code | What was ordered (see dim_products) |
| Sales Channel | Where the order was placed: Mobile App, Website or Marketplace |
| Quantity | Units in the order |
| Unit Price (INR) | Price of one unit at order time, in ₹ |
| Discount % | Discount applied to the order, in % |
| Order Value (INR) | What the customer actually paid after discount, in ₹ |
| Payment Method | UPI, Credit/Debit Card, Cash on Delivery or Net Banking |
| Order Status | Delivered, Returned or Cancelled |
| Delivery Days | Days from order to delivery |

## outputs/ — KPI result tables
| File | What it shows |
|---|---|
| kpi_summary.csv | Headline numbers: Total Revenue, Orders, Average Order Value, Gross Margin %, Return Rate %, Repeat Customer % |
| sales_by_channel.csv | Orders, revenue, share, AOV and return rate per sales channel |
| sales_by_category.csv | Orders, units, revenue, margin % and return rate per product category |
| sales_by_region.csv | Orders, revenue and AOV per region (North / South / East / West) |
| top_products.csv | Top 15 products by revenue, with return rates |
| customer_segments.csv | One-time vs Repeat vs Loyal buyers: customers, orders, revenue share |
| monthly_trend.csv | Month-by-month orders and revenue with MoM and YoY growth % (LAG) |
| weekly_trend.csv | Week-by-week orders and revenue with WoW growth % |
| yearly_summary.csv | Year-by-year totals with YoY growth % (2025 = Jan–Jun, partial year) |

**Note:** synthetic sample data generated by `python/generate_sample_data.py`
(seed 42) for demonstration — modelled on a real project structure,
no real company data.
